# Audiris

<img width="2060" height="2060" alt="logo" src="https://github.com/user-attachments/assets/71c296b8-cd7d-4124-8482-8b04c2e120e7" />

> **High-Fidelity Audio Visualization Engine (Rust & Tauri)**

Audiris is a proprietary, high-performance desktop engine built to render audio frequencies into dynamic, frame-perfect visual experiences. 

### ℹ️ About This Repository
This repository serves as the official landing page and issue tracker for Audiris. **The core engine and source code are currently closed-source and in active internal use.** 

### 🔥 Features (Current Internal Build)
* **Zero-Latency Audio Processing:** Powered by Rust's memory-safe architecture.
* **Hardware Accelerated Rendering:** Seamless integration with FFmpeg for ultra-fast video generation.
* **Customizable Parameters:** Dynamic control over shapes, color palettes, and reactivity.

*Audiris is currently an in-house tool and not available for public download. Stay tuned for future updates regarding a potential public release.*
